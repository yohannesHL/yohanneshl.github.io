
# Yohannes Libanos — Personal Website

A static personal portfolio built with [Astro](https://astro.build) and design-token-driven CSS.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The static output is written to `dist/` and can be deployed to GitHub Pages.

## Project structure

- `src/layouts/` — Astro page layouts.
- `src/components/` — Section and UI components.
- `src/styles/` — Global styles and CSS design tokens (`tokens.css`).
- `src/scripts/` — Client-side scripts (project carousel).
- `public/` — Static assets served at root (`/img/...`, favicon, etc.).
